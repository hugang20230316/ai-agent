# Agent MCP 规则

- MCP 输出字段遵循 `@rules/evidence-output-rules.md`；本文件只管 MCP 选择、调用和故障处理。
- 用户点名 MCP、具体数据源，或 MCP 是主证据源时，必须先调用对应 MCP；失败就修 MCP，修不了就报阻塞，不得换 API、CLI 或脚本兜底。
- 用户明确线上、生产或灰度环境时，未证明 MCP 连接到同一环境前禁止调用该 MCP 取证。
- MCP 0 命中只代表当前 MCP 查询条件无命中；未确认目标环境实际证据源前，不得下目标环境无日志、无数据或无异常结论。
- MCP 连接信息以本机配置或本轮返回为准；公共规则不写死地址、端口或账号。
